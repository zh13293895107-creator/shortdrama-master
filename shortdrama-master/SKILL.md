# 竖屏短剧编剧总控（锁定版）

按“选题 → 故事线圣经 → 施工级细纲 → 分集剧本 → 自检/整合”五步跑完整，先确认圣经再写正文，不跳步。所有硬约束已固化，落笔即遵守，不把已知错误再犯一遍。

## 一、五阶段工作流（每阶段停下交付等确认）

1. **选题**：给一句话故事、主力观众、对标期待、微创新、主角与对手关系、前三集、长线与结局，用户圈定后再深入。
2. **故事线圣经**：一句话故事、类型基调、世界观/能力边界、人物小传＋人物四项、两笔账、关键转折、长弧 beat、伏笔“埋—收”表；用户确认后才写细纲。
3. **施工级细纲**：每集写清承接、当集目标、情绪线、两笔账、台词交锋、实际结果、集尾钩子，看得出前一集怎么造成后一集。
4. **分集剧本**：按 XML 格式写正文，落实冷开场、冲突 2—3 轮、反转、钩子；画面只写看得见的，动机进 OS。
5. **自检与 Word 整合**：七门机器 FAIL 清零＋人工逐条 ✓，再用 `assemble_docx.py` 整合 Word。

## 二、每集锁定口径（最常被纠正，先记住）

- 成片卡 80 秒不超；发声净字 260—280（4 字/秒，不含标点），动作预留约 10 秒；动作多的集压到 260—270。
- **每句台词/OS 都必须有情绪功能**（加压、顶回、戳破、心疼、说死、抛悬念），没有一句填空话。
- 台词完整、一针见血，把“赌注＋心情”一句说破；禁止半截省略句、禁止碎句空顶；冲突 2—3 轮、每轮更狠。
- 小学生大白话，禁抽象/象征/隐喻/镜头术语/分镜腔；情绪落到具体动作。
- 关键信息用台词/OS 说破，只听不看也能懂，不让观众推理。
- 站位、动机、因果符合物理空间合理性；一场戏不晾人，对在场人说的话必须有反应。
- 60 集封顶不加集，装不下改大纲；伏笔埋了必须收。

## 三、交稿前七门（按顺序，全过才交付）

脚本在 `scripts/`，可对 xml 或目录跑：结构总审 → 禁词扫描 → 时长（本技能锁定口径，无假超时）→ 制作密度（△≥120、表演覆盖≥0.8）→ 钩子承接 → 悬空引用 → 逐行审核；再用 `review_lines.py` 做遮名辨人与只听不看。机器 FAIL 清零且人工逐条 ✓ 才允许交付；偷懒、半截、跳戏即整集重做。

## 四、禁止再犯清单（每条都对应一次返工）

1. 不按旧 208 口径写，不把 count_timing 的旧假超时当回事。
2. 不写缺斤少两的半截话、不让观众猜意思。
3. 不堆“嗯啊行好”的细碎对话，每轮交锋是整句、切要害。
4. 不写纳闷、发紧、一僵、脸沉等抽象词；画面行不用他/她，不用手指/指头忙手。
5. 不让同角色连续台词中间没有对方反应；不把“那句”写成悬空引用。
6. 不把关键信息只放画面；不写无叙事功能的空镜呆站、不注水。
7. 不机械砍字断因果；不在原文件上反复改，新建干净文件并在生成逻辑里改。
8. 不未审就交付；不擅自加集；有孩子主角时不抢孩子的情绪高点。
