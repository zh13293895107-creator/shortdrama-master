# 每集施工蓝图：情绪结构、台词功能与主视角

## 一、每集剧情情绪结构（四件套＋第五项必做）

动笔前先把这五样填齐，缺一项不许落笔：

1. **主角情绪线（4—5 个具体情绪）**：按“起 → 受压 → 破防/心疼 → 拿定主意 → 安心/恳求”逐级升级，每个情绪都具体、可演。
2. **两笔账**：
   - 看得见的损失：具体的钱、物、处境，数得清、对得上。
   - 关系上的亏欠：人情、期待、被拿走的情分，给完整反应。
3. **台词切中要害**：整句说破“赌注＋心情”，冲突 2—3 轮、每轮更狠，不堆碎句。
4. **功能段标签（内部规划，不写进成品）**：冷开场 → 冲突进来 → 再压一次 → 反转 → 钩子。
5. **【必做】每句台词/OS 都有情绪功能**，按下表逐句核对。

## 二、每句台词/OS 的六类情绪功能（逐句可核对）

每句话必须至少落在其中一类，否则就是废话，重写：

1. **加压逼一步**：把对方往死角再推一下，逼他表态。
2. **顶回去亮态度**：当众把自己的立场和底线说清楚。
3. **戳破硬撑**：把对方嘴上不认、实际在撑的事当面点破。
4. **流露心疼**：把舍不得、担心、难受直接说出来。
5. **把决定说死**：把自己的选择和条件讲到没有商量余地。
6. **抛新悬念**：抛出一个让人想看下一集的新问题或新后果。

## 三、对话是一切基础

1. 结构、节奏、冲突、反转、钩子全靠台词交锋；一场核心对话可撑一整集，一个场景可跨多集，不硬切。
2. 冲突要有来有回、有反转或打脸，不让一个人把话说完、对方没反应。
3. 钩子（▷）必须在下一集开头由当事人当面回应、直接接招，不靠旁人转述、画外音复述或另起炉灶。

## 四、长弧五段（60 集默认结构）

1. **1—10 立仇交锋**：兑现第一件事，主角第一次能做自己的选择。
2. **11—30 做大**：事情变大，有人担责也有人抢决定权，从做成一件进到批量交货。
3. **31—38 去留**：矛盾压到主角最想保住的东西，安排一次主角主动做出的难决定。
4. **39—50 复起**：前面做过的事起作用，帮过的人出面，主角亲手完成关键行动。
5. **51—60 回收**：先把利益结清，再落关系；终场找回开头的动作或物件，让观众看见变化。

## 五、伏笔纪律

1. 埋了的伏笔必须收，建一张“埋—收”对照表，终集前逐条勾销。
2. 常见伏笔类型：一枚硬币/发卡、两根木棍、一句口头禅、账本上的旧数、一张小板凳、固定时间的电话、工友的手艺、一笔没付的钱。
3. 每个转折的证据必须在前文出现过，禁止为反转而反转。

## 六、萌宝/孩童主视角六条（有孩子主角时全程统一）

1. 视线跟着孩子：每个关键段落先给孩子的动作/反应，再带大人交锋；大人冲突通过孩子的眼睛和 OS 呈现，不从大人争吵开场。
2. 每集冷开场先给孩子一个孩子式的小动作、小念头，先立可爱天真。
3. 大人台词只给压力、交代背景、给反应，不抢孩子的情绪高点，最响那句留给孩子。
4. 守住孩童边界：议价、报损、送货、看设备、租柜归成年人；孩子只管数钱、知道谁没吃饭、看见抢棍、出孩子式主意、摸发卡、摆木棍、写认得的字。
5. 孩子的小算盘、心疼、害怕靠 OS，不写进画面。
6. 括号里写“动作＋准确情绪词”，发声仍按 4 字/秒、260—280，画面/动作/台词并行。

## 七、人物四项（写场次前为每个主要人物填）

1. 他眼下要保住什么。
2. 他怕这件事被谁知道。
3. 他觉得对方欠什么。
4. 他用哪个动作遮掩。
