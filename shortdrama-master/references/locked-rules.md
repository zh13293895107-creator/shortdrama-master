# 锁定铁律（写剧本全程不可违反）

本文件是硬约束，不是参考建议。每条都对应一次实际返工，落笔前逐条对照。

## 一、体量与时长（锁定口径）

1. 竖屏 9:16，单集成片卡 80 秒不超，2—4 场。
2. 发声净字 260—280（4 字/秒，不含标点）；独立动作偏多的集压到 260—270，不硬凑 280。
3. 发声时间约 65—70 秒，气口、独立动作、反应、剪接合计约 10 秒，成片 75—80 秒。
4. 标点不占发声字，只用逗号、句号、冒号、感叹号、问号把语气和停顿节奏写出来。
5. 全剧默认 60 集封顶，装不下就改大纲细节，绝不加集。

## 二、台词第一原则（最高优先级）

1. 每一句台词和 OS 都必须有情绪功能，没有一句是凑数的填空话。六类功能见 `episode-blueprint.md`。
2. 台词要完整、一针见血：一句话把“眼下的赌注＋人物此刻的心情”一起说破、说完整。
3. 禁止缺斤少两、半截省略句，禁止让观众猜意思；念给没看过剧情的人听，不用解释就能懂。
4. 禁止对话太细碎：不要一堆“嗯、啊、行、好”的碎句来回顶。冲突分 2—3 轮实打实交锋，每轮是整句、一轮比一轮狠。
5. 次要过场用大白话蒙太奇几秒带过，不写无叙事功能的空镜、呆站和冗余停顿。
6. 台词是活人当下会说的话，口语化，有口头语、停顿、打断；遮名只看台词也能认出是谁。

## 三、小学生大白话（最高文字原则）

1. 像小学生写东西，用最直白的话写清谁、做什么、说什么、什么心情。
2. 禁止抽象、象征、隐喻、不明确的词，禁止镜头术语和分镜腔。
3. 眼神、表情、情绪都落到具体动作和大白话上（如“盯着他，咬了咬牙”“脸上带着笑”），不写“发亮、发紧、眼里换上一层阴、像一块石头”。
4. 不用多义词和压缩句，不靠破折号硬压，禁止翻案腔。
5. 压缩字数必须保住因果和动机，禁止机械砍字；逻辑断了就整体重写。

## 四、直白表达与只听不看（观众零思考）

1. 开场 3 秒内把“谁是好人、谁是反派、什么冲突”拍明白；主要人物第一次出场身份立场就点破。
2. 人物关系、善恶、前因后果、委屈、下一步，全部用画面＋台词/OS 直接说破，不让观众推理。
3. 只听不看也能懂：关键信息不能只放画面、字幕或道具，凡只在画面里的关键信息，台词/OS 必须补一句说破。
4. OS 只补画面看不到的东西（态度、计划、秘密、门道、动机）；画面已交代清楚的不再用 OS 复述，不点名认人。

## 五、物理空间合理性（强制检查）

1. 人物站位、行为动机、因果逻辑必须符合现实世界规律。
2. 人在哪个位置、什么时候才看得到，决定他什么时候动；不会对自己早就知道的东西露出惊讶。
3. 动作按物理过程补齐：敲门后住户先调小音量再开门、报警人随警上楼指认、说话要先坐下再开口等。
4. 每个动作都有功能（推动情节、表现决定、操作物件、符合物理过程），不写无来由的空忙手，不写与前后矛盾或重复的动作。
5. 一场戏有头有尾、不晾人：对着在场角色说的话必须有对方反应；没人接就改成自言自语或 OS。

## 六、交付与返工纪律

1. 每集写完先跑七门、机器 FAIL 清零，再人工逐条核对，全部通过才交付。
2. 发现偷懒、台词半截、跳剧情、违规，整集重做，不带问题往下写。
3. 没达到所有要求就不拿给用户看；不把未审核内容交付。
4. 修改时新建干净文件，不在原文件上反复改；优先在转换/生成逻辑里改，保证可复现。
5. 每个生产环节先停下交付、等用户确认，再进下一环节，不自动连续往下做。
