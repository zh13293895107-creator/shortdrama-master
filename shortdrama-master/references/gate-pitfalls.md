# 七门判读口径与已知脚本坑

## 一、交稿前按顺序跑七门（机器 FAIL 清零＋人工逐条 ✓）

脚本都在 `scripts/`，可对单个 xml 或整个目录跑：

1. `check_structure.py`：结构总审，查开头/中段冲突/结尾钩子＋钩子回应，打印人工签字表。
2. `scan_script.py`：禁词、说教、画面心理词、批注、标签配平、集数连续。
3. `count_timing.py`：本技能已改锁定口径，净字 260—280、动作 10 秒、成片≤80，不再打旧的假超时。
4. `check_density.py`：每场有画面、△ 总字 ≥120、表演提示覆盖 ≥0.8、口号/摘要腔。
5. `check_hook_link.py`：钩子承接硬筛；无关键词重合标“待人工”，需闭眼听确认。
6. `check_reference.py`：悬空引用，OS/台词引用的词必须在前面真实说出口。
7. `review_each_line.py`：逐行硬判代词/抽象/摘要/悬空/反应；再用 `review_lines.py` 做遮名辨人与只听不看。
8. 整合 Word：`assemble_docx.py --title "剧名" --front front.xml --parts p1.xml ...`

## 二、禁词与必改词（机器实测，命中即 FAIL）

1. 去 AI 味禁词：然而、不禁、仿佛、似乎、缓缓、轻轻、微微、顿时、瞬间、深深、钉在原地、闪过一丝、嘴角勾起、油然而生、情不自禁。用“慢慢、一点点、一下”等口语词替代。
2. 抽象/分镜词（画面行与括号都判）：发亮、发紧、发蒙、发颤、发酸、纳闷、闷声、慢声、赔笑、讪、捻、摊着、人影晃、当心、踩上、压过来、一层阴。
3. 括号禁词：气音、一僵、脸沉；说教词：硬道理、吃得苦中苦、人善被人欺、合法、才是。
4. OS/心声禁格言普法腔：这种东西/这种事/这种人、趁早、终究、终归、向来、从来、不过是、无非是、只不过、罢了、而已、说白了、所谓、这就是、道理。
5. 画面行禁心理词：心说、心里、暗自、心想、暗忖、心道、心中、心头、暗喜、盘算、本想、假意、故作、内心；判断和动机一律转 OS。

## 三、画面行写法硬坑

1. 画面行（△、▷、括号、引语）出现“他/她”即 FAIL，一律改全名；OS/台词正文里的他/她不判。
2. 画面行/括号出现“手指、指头”即判空忙手 FAIL，改自然动作（指了指、伸手、算珠拨得响）。
3. 画面行统一不带编号：带编号的 △ 行会被漏检。
4. 只有括号、没有冒号的角色行不被识别，转成 △ 或补台词。
5. 画面行只写镜头看得见的动作、表情、走位、道具、景别；具体写清谁做了什么、怎么做。

## 四、反应硬门（NO-REACT）

1. 同一角色连续发声、中间没有任何画面行（对方没接话、没动作）即 FAIL；在两句之间插一条对方看得见的 △。
2. 非 OS 发声后紧跟同角色的 OS 也会 FAIL，必须在中间插 △。
3. 场尾最后一句是对在场人说的、后面没反应画面，判晾人 FAIL；要么给反应，要么改成自言自语/OS。
4. 中间有画面行会列“待人工确认”，要确认画面真的是对方在反应。

## 五、悬空引用（DANGLING）

1. “这句/那句/就一句 X”“这俩字”引用的词，必须在前面真实说出口的台词里出现；前面没人说“心善”，就不能写“就一句心善”。
2. 两个脚本的引用正则不同：check_reference 在去标点后，“那句/这句”后紧跟的 1—4 字若没在之前发声出现即 DANGLING。
3. 最稳的规避写法：把“那句”改成“的话、这件事”等不含“句”的说法；要概括就对着真实台词说。

## 六、摘要腔与数字罗列

1. 一句话里出现 ≥2 个“数字＋单位”、没有语气词、且整句 <22 字，判数字罗列摘要腔；加句末语气词（啊呢吧呀嘛）或把话说完整即可。
2. 口号腔（SLOGAN）：一分分挣、靠的是、才是硬道理、吃得苦中苦、人善被人欺等，命中即 FAIL。
3. 单位词覆盖：块毛分只条刀亩罐等；写钱和数量时同时带情绪，不写成报表。

## 七、人物感与只听不看（人工总门）

1. 用 `review_lines.py`：默认逐角色列台词，`--anonymous` 做遮名辨人，`--audio` 出纯听版。
2. 朗读测试：拗口、像念稿、像讲道理的重写。
3. 遮名辨人：认不出是谁＝人物没立住，回圣经补语言风格。
4. 只听不看：盖住画面只听台词 OS，要能听懂讲什么、谁对谁错、该代入什么情绪，并且想接着听。
